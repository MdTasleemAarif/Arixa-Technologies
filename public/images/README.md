# Arixa Technologies Image Folders

Place generated WebP assets in these folders:

- `home/`
- `about/`
- `services/`
- `blog/`
- `contact/`
- `og/`
- `common/`

The code references the exact paths documented in `src/config/site-assets.ts` and `docs/IMAGE-ASSET-GUIDE.md`.
The current committed assets use PNG paths. If you convert them to WebP later, update `src/config/site-assets.ts`, `docs/IMAGE-ASSET-GUIDE.md`, and seed image paths together.
