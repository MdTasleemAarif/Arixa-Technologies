## Image SEO Rules

- Use descriptive filenames.
- Use natural alt text.
- Prefer WebP.
- Compress images before deployment.
- Keep width and height consistent with the manifest.
- Use topic-matched blog featured images.
- Use one strong OG image for social sharing.
